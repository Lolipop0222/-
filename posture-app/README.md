# 공부 자세 측정기 (목 각도 측정 웹앱)

옆에서 찍은 영상으로 **목 각도**(고개를 얼마나 숙였는지)를 재는 탐구용 웹앱이에요.
서버·로그인·DB 없이 브라우저에서만 돌아가고, **영상과 사진은 저장하거나 전송하지 않습니다.** 남는 것은 각도 숫자 기록뿐이에요.

탐구 질문
1. 화면 알림(피드백)이 자세 자기조절을 돕는가? → **측정 세션**의 알림 ON / OFF 비교
2. 독서대 각도에 따라 목 각도가 달라지는가? → **측정 세션**(조건 이름) 또는 **추천 독서대 각도 찾기**

---

## 1. 파일 구조

```
posture-app/
├─ index.html          화면 전체 (한 페이지)
├─ css/style.css       꾸밈
├─ js/
│  ├─ angle.js         ★ 목 각도 계산 (보고서에서 설명할 부분)
│  ├─ quadfit.js       ★ 2차 곡선 맞추기 + 최저점 (보고서에서 설명할 부분)
│  ├─ stats.js         요약 통계, 알림 판정, 추천 판단, CSV 만들기
│  ├─ storage.js       브라우저에 기록 저장 (안 되는 환경에서도 멈추지 않음)
│  ├─ pose.js          카메라 열기 + MediaPipe PoseLandmarker 불러오기
│  └─ app.js           화면 동작
├─ tests/
│  ├─ cases.js         테스트 내용 (답을 아는 값으로 계산 확인)
│  ├─ run-tests.mjs    Node.js로 실행
│  └─ tests.html       브라우저로 실행
└─ package.json        (테스트 실행용. 설치할 것은 없음)
```

## 2. 실행 방법

카메라는 주소가 `https://`로 시작하거나 `localhost`일 때만 열려요. 파일을 더블클릭해서 여는 것(`file://`)은 안 됩니다.

### A. 노트북에서 바로 실행 (localhost)

1. 이 `posture-app` 폴더를 노트북에 내려받아요. (GitHub 저장소 화면 → 초록색 **Code** → **Download ZIP** → 압축 풀기)
2. 파이썬이 있으면 (없으면 [python.org](https://www.python.org/downloads/)에서 설치, 설치 화면에서 *Add python.exe to PATH* 체크)
   - 윈도우: `posture-app` 폴더를 연 탐색기의 주소창에 `cmd`를 치고 엔터 → 검은 창에 `python -m http.server 8000`
   - 맥: 터미널에서 `cd `를 치고 폴더를 끌어다 놓고 엔터 → `python3 -m http.server 8000`
3. 크롬에서 **http://localhost:8000** 을 열어요.
4. 카메라 권한을 물으면 **허용**.
5. 끝낼 때는 검은 창에서 `Ctrl + C`.

> VS Code를 쓴다면 확장 프로그램 **Live Server**를 설치하고 `index.html`에서 오른쪽 클릭 → *Open with Live Server* 해도 됩니다.
>
> 같은 와이파이의 폰에서 `http://노트북IP:8000`으로 여는 것은 **안 돼요** (https가 아니라서 카메라가 막힘). 폰은 아래 B 방법을 쓰세요.

### B. GitHub Pages로 올려서 폰에서 열기 (https)

1. [github.com](https://github.com)에 로그인 → 오른쪽 위 **+** → **New repository**.
2. 이름을 정하고(예: `posture`) **Public**을 고른 뒤 **Create repository**.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 눌러요.
4. `posture-app` 폴더 **안에 있는 것들**(`index.html`, `css`, `js`, `tests` …)을 모두 끌어다 놓고 **Commit changes**.
   - `index.html`이 저장소 맨 위에 보여야 해요. (`posture-app` 폴더째 올리면 주소 끝에 `/posture-app/`을 붙여야 합니다)
5. 저장소의 **Settings** → 왼쪽 **Pages** → *Build and deployment*의 **Source: Deploy from a branch**, **Branch: main / (root)** → **Save**.
6. 1~2분 뒤 같은 화면 위쪽에 주소가 나와요: `https://내아이디.github.io/posture/`
7. 폰의 **크롬(안드로이드) / 사파리(아이폰)** 에서 그 주소를 열고 카메라를 **허용**.
   - 카카오톡·인스타 안에서 열리는 브라우저는 카메라가 안 될 수 있어요. 주소를 복사해 크롬/사파리에 붙여 넣으세요.
8. 파일을 고치면 같은 방법으로 다시 올리면 돼요. (반영까지 1~2분, 폰에서 새로 고침)

## 3. 사용 방법

### 촬영 준비
- 폰(노트북)을 앉은 사람의 **옆쪽 1~1.5m**에 세워요. **머리와 어깨**가 화면에 다 들어오게.
- 귀가 머리카락·후드에 가리지 않게. 카메라 높이는 어깨~귀 높이쯤, 기울지 않게 똑바로 세워요(기울면 수직선이 틀어집니다).
- 측정 중에는 이 화면을 **켜 둔 채로** 두세요. 다른 앱으로 넘어가면 그동안은 "측정 불가"로 기록됩니다.

### 측정 세션
1. 참여자 코드, 조건 이름, 측정 시간(기본 20분), 기준 각도(기본 20°), 모드를 정해요.
2. **카메라 맞추기** 화면에서 귀·어깨에 점이 찍히는지 확인하고 **측정 시작**.
3. 시간이 다 되면 자동으로 끝나고 요약이 나와요. **CSV 내려받기**를 누르세요.

| 모드 | 화면 |
|---|---|
| 알림 OFF | "측정 중"과 남은 시간만. 실시간 각도는 보여 주지 않음 |
| 알림 ON | 실시간 각도 표시. 기준 각도 이상이 5초(바꿀 수 있음) 이어지면 화면 테두리가 빨갛게 바뀌고 "고개를 들어 보세요". 자세가 돌아오면 사라짐. 소리는 기본 꺼짐 |

### 정확도 검증
1. **지금 멈춰서 재기** → 화면이 멈추고 귀·어깨 점, 연결선(노란 실선), 수직 기준선(흰 점선), 각도 값이 그려져요.
2. 멈춘 화면에 각도기를 대고, 어깨 점을 중심으로 **흰 점선과 노란 선 사이의 각도**를 재요.
3. 아래 목록의 "각도기(°)" 칸에 적으면 오차(앱 − 각도기)와 **평균 오차**(|앱 − 각도기|의 평균)가 나와요.
4. 여러 자세(똑바로, 조금 숙임, 많이 숙임)로 5번 이상 해 보는 것을 권해요. **검증 기록 CSV**로 내보낼 수 있어요.

### 추천 독서대 각도 찾기
1. 학생 코드, 시험할 각도(기본 30°·45°·60°, 추가·삭제 가능, 최소 3개), 각도마다 측정 시간(기본 3분)을 정해요.
2. 앱이 "독서대를 45°로 맞추고 시작을 누르세요"처럼 순서대로 안내해요. (순서 섞기 기본 켜짐)
3. 각 측정이 끝나면 편안함 점수(1~5)를 넣어요. 유효 데이터가 70% 미만이면 다시 측정하라고 권해요.
4. 결과: 추천 각도, 추정 최적 각도, 그래프, 표, CSV.

### 지난 기록
측정 세션과 추천 결과가 이 브라우저에 저장돼요. CSV를 다시 내려받거나 지울 수 있어요.
(기기·브라우저마다 따로 저장됩니다. 인터넷 기록을 지우면 같이 사라지니 **측정 직후 CSV를 받아 두세요.**)

## 4. 계산 원리 (보고서용)

### 목 각도 — `js/angle.js`

"어깨→귀" 선이 "똑바로 위(수직선)"와 이루는 각도예요. 0° = 귀가 어깨 바로 위, 클수록 고개를 앞으로 숙인 것.

```
가로 = |귀x − 어깨x|
위로 = 어깨y − 귀y        ← 사진 좌표는 y가 아래로 갈수록 커지므로 뒤집어 뺀다
목 각도 = atan2(가로, 위로) × 180 / π
```

- MediaPipe는 좌표를 0~1 비율로 주기 때문에, 각도를 구하기 전에 **픽셀로 바꿔요**(x × 가로 길이, y × 세로 길이). 안 그러면 화면이 정사각형이 아닐 때 각도가 틀어져요.
- 귀는 랜드마크 7(왼쪽)/8(오른쪽), 어깨는 11/12. 귀+어깨의 visibility 합이 큰 쪽(카메라 쪽)을 자동으로 골라요.
- 귀나 어깨의 visibility가 0.5 미만이면 그 프레임은 "측정 불가".

### 2차 곡선과 최저점 — `js/quadfit.js`

(독서대 각도 x, 평균 목 각도 y) 점들에 `y = a·x² + b·x + c`를 **최소제곱법**(곡선과 점 사이 세로 거리의 제곱을 모두 더한 값이 가장 작게)으로 맞추고, 꼭짓점 `x = −b / (2a)`를 "추정 최적 각도"로 봐요.
`a > 0`(∪ 모양)이고 꼭짓점이 측정한 범위 안에 있을 때만 추정해요.

### 테스트

답을 이미 아는 값으로 계산이 맞는지 확인해요. (예: 귀가 어깨 바로 위 → 0°, 45° 방향 → 45°, 30°→25·45°→15·60°→25 → 최저점 45°)

- 브라우저: 앱 주소 뒤에 `tests/tests.html`을 붙여 열기 (예: `http://localhost:8000/tests/tests.html`)
- Node.js가 있으면: `node tests/run-tests.mjs`

## 5. CSV 파일

엑셀·구글 시트에서 바로 열려요(한글이 깨지지 않게 UTF-8 BOM을 붙였어요).

| 파일 | 내용 |
|---|---|
| `자세_코드_조건_날짜-시각.csv` | 위쪽: 세션 정보와 요약(항목, 값). 한 줄 띄우고 아래쪽: 1초별 기록 — 경과 시간(초), 목 각도(도), 측정 가능(1/0), 알림 표시(1/0) |
| `자세_세션요약_….csv` | 저장된 모든 세션의 요약을 한 줄씩 (조건끼리 비교용) |
| `자세_정확도검증_….csv` | 번호, 시각, 앱이 잰 각도, 각도기로 잰 각도, 오차, 오차 절댓값, 평균 오차 |
| `자세_독서대추천_….csv` | 학생 코드, 독서대 각도, 측정 순서, 평균 목 각도, 기준 각도 이상 비율, 편안함 점수, 유효 데이터 비율, 추정 최적 각도 |

## 6. 결정한 것

요청에 정해져 있지 않아서 합리적으로 정한 것들이에요. 바꾸고 싶으면 알려 주세요.

**각도**
- 목 각도는 **방향 없이 0°~180°** 로 계산해요(가로 거리에 절댓값). 왼쪽을 보고 앉든 오른쪽을 보고 앉든 같은 값이 나오지만, 고개를 **뒤로 젖혀도 양수**로 나와요. 공부 자세에서는 거의 없는 경우라 단순한 쪽을 골랐어요.
- 1초에 약 **10번** 재요(배터리·발열을 줄이려고). 화면에 보이는 값과 알림 판단은 **최근 1초 평균**을 써요.
- 자세 인식 모델은 MediaPipe `pose_landmarker_full`(lite보다 정확, heavy보다 가벼움), 라이브러리 버전은 `0.10.14`로 고정. `js/pose.js` 맨 위에서 바꿀 수 있어요.

**1초별 기록**
- 그 1초의 목 각도 = 그 1초 동안 측정 가능했던 프레임들의 **평균**(소수 첫째 자리).
- 그 1초 동안 본 프레임의 **절반 이상**에서 귀·어깨가 보였을 때만 "측정 가능(1)". 아니면 각도 칸을 비워요.
- 화면을 끄거나 다른 앱으로 가서 못 잰 시간은 "측정 불가(0)"로 채워요(시간은 계속 흐름).

**요약**
- 평균 목 각도 = 측정 가능했던 초들의 평균.
- **기준 각도 이상 비율 = 기준 이상인 초 ÷ 측정 가능했던 초**. (측정 불가였던 초는 분모에서도 뺌)
- 유효 데이터 비율 = 측정 가능했던 초 ÷ 전체 초.
- 알림 OFF 세션도 기준 각도 이상 비율은 계산해요(ON과 비교하려고). 알림 횟수는 ON에서만.
- "측정 끝내기"로 일찍 끝내도 그때까지의 기록은 저장돼요. 1초가 안 되면 저장하지 않아요.

**알림**
- "기준 각도 **이상**(≥)"이 정해진 시간 동안 **끊기지 않고** 이어져야 켜져요. 중간에 한 번이라도 기준 아래로 내려가거나 측정 불가(1초 넘게)가 되면 처음부터 다시 세요.
- 꺼지는 것은 기준 아래로 내려오는 즉시. 알림 횟수 = 꺼져 있다가 켜진 횟수.
- 소리는 알림이 **켜지는 순간 짧게 한 번**만.
- 측정 중에는 **카메라 화면을 숨겨요**(자기 모습을 보는 것도 피드백이 될 수 있어서). 대신 "자세 인식 중 / 측정 불가" 한 줄은 두 모드 모두 보여 줘요 — 귀가 가려져 데이터가 통째로 날아가는 것을 막으려고요. 이것도 가리고 싶으면 알려 주세요.
- 측정 전 "카메라 맞추기" 화면에서도 각도 숫자는 보여 주지 않고 점과 선만 보여 줘요.

**정확도 검증**
- 멈춘 화면의 각도는 **그 한 장만으로** 잰 값이에요(1초 평균 아님) — 그림과 숫자가 정확히 같은 순간이 되도록.
- 오차 = 앱 − 각도기. **평균 오차 = 절댓값의 평균**. 각도기 값을 안 넣은 줄은 뺌.
- 전면 카메라는 미리보기처럼 좌우를 뒤집어 보여 줘요(각도는 같아요).
- 멈춘 화면(사진)은 저장하지 않고 "다시 찍기"나 화면을 나가면 지워져요. 목록에는 숫자만 남아요.

**추천 독서대 각도**
- 순서를 섞지 않으면 작은 각도부터 측정해요.
- 편안함 점수를 넣어야 다음으로 넘어가요. 그 화면에서 "이 각도 다시 측정"을 할 수 있어요.
- 2차 곡선이 ∩ 모양이거나 직선이라 최저점이 없으면, 곡선이 더 낮은 쪽 끝 방향으로 "더 낮은/높은 각도도 측정해 보세요"라고 안내해요.
- 평균 목 각도가 아예 없는(유효 0%) 측정은 순위와 곡선에서 빼요. "신뢰 낮음"(유효 70% 미만)이지만 평균이 있는 측정은 포함하되 표시해요.
- "1등·2등 차이가 측정 오차 안"인지는 **이 기기에 저장된 검증 기록의 평균 오차**와 비교해요. 그래서 검증을 같은 기기에서 먼저 해 두어야 해요.
- 편안함 경고는 추천 각도보다 **2점 이상 높은** 각도가 하나라도 있으면 띄워요.
- 각도별 측정의 1초별 원자료도 "지난 기록"에 세션으로 남아요(조건 이름: `독서대 45도 (추천 모드)`).

**기타**
- 측정 시간 칸에는 소수도 넣을 수 있어요(연습용으로 `0.5`분 등).
- 기록은 브라우저 `localStorage`에 저장해요. 저장이 막힌 환경(사생활 보호 모드 등)에서는 첫 화면에 경고를 띄우고, 창을 닫기 전까지만 기억해요.
- 화면은 기기의 밝은/어두운 모드를 따라가요.

## 7. 알아 둘 한계 (보고서의 "한계"에 쓸 수 있어요)

- 카메라가 정확히 옆이 아니거나 기울어져 있으면 각도가 달라져요. 조건끼리 비교할 때는 **카메라 위치를 고정**하세요.
- MediaPipe가 찾는 "귀"와 "어깨" 점은 해부학적 기준점과 조금 다를 수 있어요. 그래서 **정확도 검증**으로 오차를 직접 구해 보고서에 함께 적는 것이 좋아요.
- 이 각도는 병원에서 쓰는 머리–척추 각도(CVA)와 정의가 달라요(수직선 기준). 다른 연구의 숫자와 바로 비교하지 마세요.
- 처음 열 때 자세 인식 프로그램(약 10MB)을 내려받으므로 **인터넷 연결**이 필요해요.
