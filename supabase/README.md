# Supabase SQL 실행 안내

DB 정의는 **`parts/` 폴더의 조각들(01~06)**이 원본이에요. 한 번에 다 붙여넣으면 SQL Editor가 느려서 나눴어요.
**평소에는 바뀐 조각만** SQL Editor에 붙여넣고 Run 하면 돼요. 몇 번을 다시 실행해도 안전해요(기존 기록·초대코드 유지).

| 순서 | 파일 | 내용 |
|---|---|---|
| 1 | `parts/01-core.sql` | 설정·프로필·공부 기록·플래너·디데이·타이머 함수 |
| 2 | `parts/02-security.sql` | 보안·문의함·비밀번호 찾기·계정 삭제·관리자 |
| 3 | `parts/03-groups.sql` | 스터디그룹 |
| 4 | `parts/04-titles.sql` | 칭호·프로필 그림/사진 규칙·순위 |
| 5 | `parts/05-storage.sql` | 사진 프로필·프린트 아카이브 저장소(Storage)·관리자 사진 검토 |
| 6 | `parts/06-subjects.sql` | 계열(문과/이과)·과목 목록(국영수사과역+기타)·세부 항목·인강, 순위·칭호 계산 |

- 조각은 **번호 순서**대로 앞의 것이 이미 실행돼 있어야 해요.
- GitHub에서 파일을 열고 오른쪽 위 **복사 버튼(Copy raw file)** 을 누르면 한 번에 복사돼요.
- `schema.sql`은 조각을 이어 붙인 **전체본**이에요(자동 생성). 새 Supabase 프로젝트를 처음 만들 때만 쓰면 돼요.
